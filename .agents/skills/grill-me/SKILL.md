# Grill-me Skill

Stress-test a plan or design with pointed questions before implementation.

## When to use this skill

- Use this when the user asks to be grilled, challenged, or stress-tested on a plan or design.
- Use this when a proposal needs hardening on scope, risks, or alternatives.
- Do not auto-invoke on normal build requests; user must ask for a grilling session.

## How to use it

### 1. Frame the target

- Ask what is being grilled (plan, design, approach) and what success looks like.

### 2. Interview in rounds

- One hard question at a time: assumptions, edge cases, scope, rollback, verification.
- Push on vague answers; ask for specifics, numbers, or file-level impact.

### 3. Verdict

- End with a pass/fail or hardened plan: what survived, what changed, what to do next.
